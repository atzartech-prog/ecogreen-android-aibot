Mengapa Single Binary Adalah Raja di RAM 1GB & KitKat?

Pada Android KitKat 4.4 atau perangkat dengan RAM 1GB, menjalankan lingkungan penuh seperti Python interpreter (butuh ~40MB), Node.js (butuh ~80MB), atau distro Linux (butuh ~150MB) sering kali membuat sistem kehabisan memori. Akibatnya, mekanisme LowMemoryKiller (LMK) Android akan membunuh proses bot Anda di tengah jalan.

Dengan Go atau Rust, kita mengompilasi seluruh logika bot, pemanggilan Google Gemini API, dan polling Telegram ke dalam satu berkas biner ELF tunggal. Binary ini ditautkan secara statis (CGO_ENABLED=0), sehingga tidak bergantung pada library Bionic Android versi apapun dan hanya mengonsumsi ~12 MB RAM!

Source Code Golang Bot (Gemini 1.5/2.0 Flash + Telegram)

Kode ini dibuat 100% murni menggunakan standard library Go (net/http, encoding/json), tanpa dependensi eksternal, sangat cepat dan anti-bocor memori:

main.go (Ultra-Lightweight ~12MB RAM) 
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"log"
	"net/http"
	"os"
	"time"
)

// Konfigurasi via Environment Variables
var (
	telegramToken = os.Getenv("TELEGRAM_BOT_TOKEN")
	geminiApiKey  = os.Getenv("GEMINI_API_KEY")
)

type Update struct {
	UpdateID int `json:"update_id"`
	Message  *struct {
		Chat struct {
			ID int64 `json:"id"`
		} `json:"chat"`
		Text string `json:"text"`
	} `json:"message"`
}

type TelegramResponse struct {
	Ok     bool     `json:"ok"`
	Result []Update `json:"result"`
}

type GeminiReq struct {
	Contents []struct {
		Parts []struct {
			Text string `json:"text"`
		} `json:"parts"`
	} `json:"contents"`
}

type GeminiResp struct {
	Candidates []struct {
		Content struct {
			Parts []struct {
				Text string `json:"text"`
			} `json:"parts"`
		} `json:"content"`
	} `json:"candidates"`
}

// Panggil Google Gemini Flash (Free Tier)
func callGemini(prompt string) (string, error) {
	url := fmt.Sprintf("https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=%s", geminiApiKey)
	
	reqBody := GeminiReq{
		Contents: []struct {
			Parts []struct {
				Text string `json:"text"`
			} `json:"parts"`
		}{
			{
				Parts: []struct {
					Text string `json:"text"`
				}{
					{Text: "Kamu adalah AI asisten ramah di STB Android: " + prompt},
				},
			},
		},
	}

	payload, _ := json.Marshal(reqBody)
	resp, err := http.Post(url, "application/json", bytes.NewBuffer(payload))
	if err != nil {
		return "", err
	}
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	var gResp GeminiResp
	if err := json.Unmarshal(body, &gResp); err != nil {
		return "Maaf, terjadi kesalahan parsing respons AI.", nil
	}

	if len(gResp.Candidates) > 0 && len(gResp.Candidates[0].Content.Parts) > 0 {
		return gResp.Candidates[0].Content.Parts[0].Text, nil
	}
	return "Maaf, AI tidak memberikan jawaban.", nil
}

// Kirim balasan ke Telegram
func sendTelegram(chatID int64, text string) {
	url := fmt.Sprintf("https://api.telegram.org/bot%s/sendMessage", telegramToken)
	data, _ := json.Marshal(map[string]interface{}{
		"chat_id": chatID,
		"text":    text,
	})
	http.Post(url, "application/json", bytes.NewBuffer(data))
}

func main() {
	if telegramToken == "" || geminiApiKey == "" {
		log.Fatal("Wajib set TELEGRAM_BOT_TOKEN dan GEMINI_API_KEY!")
	}

	log.Println("🌱 EcoGreen AI Bot Engine (Go Single Binary) Running...")
	offset := 0

	for {
		url := fmt.Sprintf("https://api.telegram.org/bot%s/getUpdates?timeout=30&offset=%d", telegramToken, offset)
		resp, err := http.Get(url)
		if err != nil {
			time.Sleep(5 * time.Second)
			continue
		}

		body, _ := io.ReadAll(resp.Body)
		resp.Body.Close()

		var tgResp TelegramResponse
		json.Unmarshal(body, &tgResp)

		for _, update := range tgResp.Result {
			offset = update.UpdateID + 1
			if update.Message != nil && update.Message.Text != "" {
				userMsg := update.Message.Text
				chatID := update.Message.Chat.ID
				log.Printf("[Chat %d] Tanya: %s", chatID, userMsg)

				aiReply, err := callGemini(userMsg)
				if err != nil {
					aiReply = "Koneksi ke AI terputus. Silakan coba lagi."
				}
				sendTelegram(chatID, aiReply)
			}
		}
		time.Sleep(500 * time.Millisecond)
	}
}

Cara Cross-Compile & Deploy ke Gadget Android

Kompilasi kode di atas dari laptop/PC Anda untuk prosesor ARM (kebanyakan STB/HP lawas menggunakan ARMv7 32-bit):

Cross-Compile (Terminal / PowerShell di PC) 
# Opsi A: Golang (Sangat Praktis, Built-in Cross Compiler)
# Untuk Windows PowerShell:
$env:CGO_ENABLED="0"; $env:GOOS="linux"; $env:GOARCH="arm"; $env:GOARM="7"; go build -ldflags="-s -w" -o aibot_arm7 main.go

# Untuk Linux / macOS Bash:
CGO_ENABLED=0 GOOS=linux GOARCH=arm GOARM=7 go build -ldflags="-s -w" -o aibot_arm7 main.go

# Opsi B: Rust (Target musl static binary, ~8MB RAM usage)
rustup target add armv7-unknown-linux-musleabihf
cargo build --target armv7-unknown-linux-musleabihf --release

# ----------------------------------------------------
# Push binary ke Android via ADB:
adb connect 192.168.1.50:5555
adb push aibot_arm7 /data/local/tmp/
adb shell "chmod +x /data/local/tmp/aibot_arm7"

# Jalankan di background Android:
adb shell
cd /data/local/tmp
export TELEGRAM_BOT_TOKEN="token_anda_disini"
export GEMINI_API_KEY="api_key_gemini_anda"
nohup ./aibot_arm7 > bot.log 2>&1 &

🌟 Keunggulan Go / Rust

  • RAM Super Irit: Hanya ~12-18 MB RAM! Sisa 980 MB RAM Android tetap lega.
  • Tanpa Runtime: Tidak butuh install Termux, Python, GCC, atau Node.js.
  • Kompatibel KitKat 4.4+: Kernel Linux 3.4 atau 3.10 Android langsung mengenali format ELF arm statis.
  • Bebas Crash LMK: Jarang sekali dibunuh oleh sistem Android karena konsumsi memori yang sangat kecil.

Python Minimalis Tanpa Bloatware Framework

Banyak tutorial bot Telegram Python menggunakan library berat seperti python-telegram-bot lengkap dengan dependensi berat yang memakan 80MB+ RAM. Untuk gadget RAM 1GB, kita menggunakan skrip Python asinkron murni dengan requests atau urllib3 biasa, memangkas penggunaan memori hingga tersisa ~35 - 45 MB.

Source Code Python Bot (Gemini + Telegram)

bot_light.py (~38MB RAM) 
import os
import time
import requests

# Konfigurasi Token
TELEGRAM_TOKEN = os.getenv("TELEGRAM_BOT_TOKEN", "ISI_TOKEN_TELEGRAM")
GEMINI_KEY = os.getenv("GEMINI_API_KEY", "ISI_API_KEY_GEMINI")

GEMINI_URL = f"https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key={GEMINI_KEY}"
TG_URL = f"https://api.telegram.org/bot{TELEGRAM_TOKEN}"

def ask_gemini(prompt_text):
    payload = {
        "contents": [{"parts": [{"text": "Kamu adalah asisten AI ramah di STB Android bekas. " + prompt_text}]}]
    }
    try:
        r = requests.post(GEMINI_URL, json=payload, timeout=20)
        data = r.json()
        return data["candidates"][0]["content"]["parts"][0]["text"]
    except Exception as e:
        return f"Maaf, gagal memproses respons AI: {str(e)}"

def send_msg(chat_id, text):
    try:
        requests.post(f"{TG_URL}/sendMessage", json={"chat_id": chat_id, "text": text}, timeout=10)
    except Exception as e:
        print(f"Error kirim pesan: {e}")

def main():
    print("🌱 Python Eco-Bot running on Android...")
    offset = 0
    while True:
        try:
            res = requests.get(f"{TG_URL}/getUpdates?timeout=30&offset={offset}", timeout=35).json()
            if res.get("ok"):
                for update in res.get("result", []):
                    offset = update["update_id"] + 1
                    msg = update.get("message")
                    if msg and "text" in msg:
                        chat_id = msg["chat"]["id"]
                        text = msg["text"]
                        print(f"Pesan masuk: {text}")
                        reply = ask_gemini(text)
                        send_msg(chat_id, reply)
        except requests.exceptions.RequestException:
            # Jaringan putus/reconnect
            time.sleep(5)
        except Exception as e:
            print(f"Loop error: {e}")
            time.sleep(2)

if __name__ == "__main__":
    main()

Konsep Chroot: Akses Penuh ke Kernel Tanpa Emulasi

Metode Chroot memanfaatkan kernel Linux bawaan Android untuk mengisolasi lingkungan root file-system baru (seperti Alpine Linux atau Debian). Karena berjalan langsung di atas kernel tanpa layer emulasi ptrace, kecepatannya 100% native!

Syarat Utama: Gadget wajib sudah memiliki akses Root (su) dan disarankan memiliki RAM ≥ 2 GB (seperti STB B860H v5 atau HG680P).

2

Skrip Setup Alpine Linux Chroot (Paling Ringan)

Bash Shell (Root Shell via ADB / Terminal) 
# Masuk sebagai superuser di Android
su

# Buat direktori chroot di memori internal / SD Card
mkdir -p /data/alpine
cd /data/alpine

# Download rootfs minimal Alpine Linux ARM (hanya ~3 MB!)
wget https://dl-cdn.alpinelinux.org/alpine/v3.19/releases/armv7/alpine-minirootfs-3.19.0-armv7.tar.gz
tar -xzf alpine-minirootfs-*.tar.gz
rm alpine-minirootfs-*.tar.gz

# Mount partisi kernel Android ke direktori chroot
mount -o bind /dev /data/alpine/dev
mount -o bind /sys /data/alpine/sys
mount -o bind /proc /data/alpine/proc
mount -t devpts devpts /data/alpine/dev/pts

# Copy konfigurasi DNS internet
echo "nameserver 8.8.8.8" > /data/alpine/etc/resolv.conf

# Masuk ke dalam lingkungan Alpine Linux!
chroot /data/alpine /bin/sh

# Sekarang Anda berada di dalam Linux Alpine murni!
apk update
apk add python3 py3-pip curl

# Install bot Anda di dalam Alpine dan jalankan 24/7!

Menjalankan Chroot Otomatis Saat Booting Android

Agar bot langsung hidup saat STB disambungkan ke adaptor listrik, buat skrip di /system/etc/init.d/99aibot atau gunakan Magisk service.d.

🐧 Kenapa Alpine Linux?

  • Ukuran rootfs hanya ~3 MB (Debian biasanya 150MB+).
  • Menggunakan musl libc yang sangat ringan untuk perangkat embedded.
  • Konsumsi RAM dasar setelah boot hanya ~15-20 MB.
1

Konsep PRoot: Linux Penuh Tanpa Perlu Root

Jika gadget Anda tidak di-root (misalnya STB kantor atau HP keluarga yang tidak ingin Anda modifikasi firmware-nya), metode PRoot adalah solusinya. PRoot menggunakan syscall ptrace untuk mencegat panggilan sistem file dan mensimulasikan lingkungan root secara virtual.

Catatan Kinerja: Ada sedikit overhead CPU/RAM karena emulasi ptrace. Ideal untuk gadget dengan RAM 1.5 GB - 2 GB dan Android 5.0+.

2

Cara Install Debian / Ubuntu via PRoot-Distro di Termux

Perintah Termux (Non-Root) 
# 1. Update Termux
pkg update -y
pkg install proot proot-distro -y

# 2. Install Debian (atau Alpine untuk lebih hemat RAM)
proot-distro install debian

# 3. Masuk ke sesi Debian
proot-distro login debian

# Di dalam Debian:
apt update && apt install -y python3 python3-pip git
# Clone atau buat bot Anda di sini!

# 4. Keluar dari sesi Debian:
exit

# 5. Menjalankan skrip bot di dalam Debian langsung dari Termux background:
nohup proot-distro login debian -- python3 /root/bot.py > /sdcard/bot.log 2>&1 &

🛡️ Kelebihan PRoot

  • 100% Aman: Tidak merusak partisi sistem Android, tidak perlu unlock bootloader.
  • Paket Lengkap: Bisa menjalankan apt install seperti di server Ubuntu biasa.
  • Mudah di-reset jika terjadi error (cukup proot-distro reset debian).

Kunci utama server eco-green adalah keandalan jangka panjang, pencegahan bahaya baterai kembung, dan konsumsi daya super hemat.

Keamanan Hardware

Bahaya Baterai HP & Solusi Bypass

Jika Anda memakai smartphone bekas, JANGAN colok charger terus menerus dengan baterai terpasang! Baterai Lithium-Ion akan kembung dan berisiko terbakar dalam hitungan bulan.

Solusi Eco-Bypass: Lepas baterai fisik, gunakan modul Step-Down Buck Converter (LM2596) dari charger 5V diturunkan ke 4.0V - 4.2V dan solder langsung ke pin (+) dan (-) konektor baterai HP. HP akan menyala abadi tanpa baterai!

STB Bekas Juara EcoGreen

Kenapa STB Android Sangat Ideal?

STB bekas (seperti ZTE B860H atau Fiberhome HG680P) tidak memiliki baterai bawaan. Menggunakan adaptor DC 12V/1A atau 5V/2A bawaan pabrik dengan konsumsi daya sangat rendah: kurang dari 3 Watt saat idle. Biaya listriknya kurang dari Rp 5.000 / bulan!

Manajemen Suhu & Jaringan

Pendinginan Pasif & Port LAN

STB lawas sudah dilengkapi port Ethernet (RJ45). Gunakan kabel LAN daripada Wi-Fi agar koneksi bot ke server Telegram/Gemini tidak pernah putus akibat sleep mode Android. Buka casing atau tempelkan heatsink aluminium kecil di atas chipset SoC (Amlogic S905x) untuk suhu adem 45°C.

Auto-Boot Recovery

Otomatis Hidup Saat Listrik Menyala

Pada smartphone, jika listrik mati dan menyala kembali, aktifkan fitur auto-boot dengan perintah fastboot: fastboot oem off-mode-charge 0. Dengan ini, begitu charger mendapat aliran listrik, HP akan langsung otomatis booting menyalakan bot tanpa perlu ditekan tombol power!
